# duanap 博客：范围与实施决策

本站位于 `demos/blog`，基于 EmDash、Astro、Node standalone 和 SQLite。
当前进度以 [PROGRESS.md](./PROGRESS.md) 为准，生产操作按 [DEPLOY.md](./DEPLOY.md) 执行。

## 已确认的范围（2026-10-01）

- **不迁移旧站数据**。上线使用 `seed/seed.json` 演示内容，真实内容在后台重新维护。
- **雷池 WAF 已关闭**。放行 WAF 不再是部署前置；若以后重新启用，再验证后台、API 和 OAuth 路径。
- **QQ 互联上线后再配置**。未配置时登录页说明原因，会员功能引导到登录页，留言墙仍可匿名提交。
- 本地开发完成后保留旧站，实际切换域名流量需要单独部署指令。
- 当前托管约定是本地开发，不自动推送或创建上游 PR。

## 关键决策

| 项目         | 当前行为                                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| URL          | 保留 `/posts/{slug}`、`/life/{slug}`、`/projects/{slug}`；不把文章目录改成 `/article/`                   |
| 旧数字入口   | 通过 `src/data/legacy-redirects.json` 跳转；没有映射时返回 404                                           |
| 评论         | EmDash 原生评论。会员评论用派生身份邮箱记账，目前不等于服务端验证的会员作者身份                          |
| 会员插件     | Native 格式。fork 的 core 补丁允许 trusted raw 路由返回多条 Set-Cookie 和外站 Location，沙箱策略保持原样 |
| 公开 UI 中文 | `src/scripts/zh-copy.ts` 负责 core 文案兜底；上游提供前台 i18n 后可移除                                  |
| 匿名访问     | 会员导航和点赞计数由客户端加载，不为未登录页面渲染增加会员数据库查询                                     |
| 收藏         | 总数独立计数，列表每页 20 条，按时间倒序加载；下线内容不展示，本页数量另行说明                           |
| 部署         | Node standalone，SQLite 和上传目录位于仓库之外。失败时恢复旧产物，数据库不自动回退                       |
| 上游同步     | 功能分支已包含 core 补丁；同步上游需要评估 merge/rebase，不能假定可 ff-only                              |

## 保留备用的迁移工具

`migrate-old-site.mjs` 是当前完整工具；`migrate-from-blog-front.mjs` 是早期工具，保留作历史参考。
这些工具不属于当前上线流程，不会自动读取或导入旧站数据。

完整工具涵盖 Markdown 转换、图片入库、分类法、会员互动、评论、友链和旧 URL 映射。
映射文件与报告需要随迁移备份。将来启用迁移前，应重新检查旧库结构、目标环境、备份和 dry-run 报告。
旧的字段映射和夜间验证日志位于主目录本地 `night-work/`，不随 Git 传播。

完成本地验证后，按部署说明建立新实例、初始化管理员和演示内容，再验证源站与公网并切换流量。
